# 本地媒体库与整理

## 添加媒体目录

在“本地媒体”中添加下载根目录或现有媒体目录。应用会：

1. 递归发现视频、字幕、NFO 和图片；
2. 解析文件名中的系列、季度和集数；
3. 尝试匹配已有元数据；
4. 生成整理预览；
5. 在确认后移动并重命名文件。

## 推荐目录结构

```text
媒体根目录/
└── 系列名/
    ├── Season 01/
    │   ├── 系列名 - S01E01.mkv
    │   └── 系列名 - S01E01.zh-Hans.ass
    └── Season 02/
```

同一作品的不同季度会归入同一个系列目录；不同年份的重制版会尽量保持独立。

## 整理前检查

- 预览中的源文件仍然存在；
- 目标目录没有同名文件；
- qBittorrent 正在做种的文件没有被外部程序占用；
- 路径位于应用和下载器都能看到的文件系统中；
- 不确定时先整理一部小作品，不要一次处理整个媒体盘。
