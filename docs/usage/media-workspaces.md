# 管理模式与媒体模式

AnimateTool 现在把日常操作拆成两个工作区。它们共用同一个管理员会话，只改变界面导航和工作重点，不是两套权限系统。

## 管理模式

管理模式用于维护追番流程：

- 今日概览；
- 追番日历；
- 订阅管理；
- 番剧图鉴；
- 本地番剧；
- 系统设置。

播放器、AI 助手、系统健康和备份恢复等旧路由仍然保留，可以通过原 URL 直接打开，但不会占据管理模式的主导航。

## 媒体模式

媒体模式从 Jellyfin 实时读取内容，提供：

- 媒体首页；
- 媒体库浏览、搜索、排序和分页加载；
- 继续观看；
- 收藏；
- 系列、季度与剧集详情；
- 统一播放器和播放进度同步。

在右上角切换工作区。桌面端直接显示“管理模式 / 媒体模式”，移动端可在“更多”抽屉中切换。

## 页面记忆与播放行为

浏览器会分别记住两个工作区最后打开的页面：

```text
animate.workspace.mode
animate.workspace.last.manage
animate.workspace.last.media
```

从媒体模式切到管理模式时，当前视频会暂停并隐藏，但播放位置和媒体详情仍保留在当前浏览器内存中。切回媒体模式会恢复原页面，不会自动继续播放；点击播放按钮后才恢复。

直接打开 `/media`、媒体详情或媒体播放 URL 时会自动进入媒体模式；打开订阅、本地番剧等管理路由时会自动进入管理模式。系统设置会沿用进入前的工作区。

## 媒体提供商

首版只实现 Jellyfin，但前后端使用提供商无关的媒体模型和 URL。后续可以增加 Plex、Emby 等适配器，而不需要重新改造媒体页面和播放器状态。

浏览、详情、剧集、图片、进度和收藏请求都先经过 AnimateTool 后端。Jellyfin API Key 保存在服务器设置中，不用于媒体图片代理或 NetBird 签名地址。
