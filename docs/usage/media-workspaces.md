# 管理模式与媒体模式

AnimateTool 现在把日常操作拆成两个工作区。它们共用同一个管理员会话，只改变界面导航和工作重点，不是两套权限系统。

## 管理模式

管理模式用于维护追番流程：

- 今日概览；
- 追番日历；
- 订阅管理；
- 番剧图鉴；
- 本地番剧；
- 系统健康；
- 备份恢复；
- 系统设置。

AI 助手不再占用侧边栏入口，而是登录后常驻的全局悬浮助手。旧 `/assistant` 链接仍可使用，访问后会打开悬浮助手并返回当前工作区上次页面。

## 媒体模式

媒体模式从 Jellyfin 实时读取内容，提供：

- 媒体首页；
- 媒体库浏览、搜索、排序和分页加载；
- 继续观看；
- 收藏；
- 系列、季度与剧集详情；
- 统一播放器和播放进度同步。

在右上角切换工作区。桌面端直接显示“管理模式 / 媒体模式”，移动端可在“更多”抽屉中切换。

媒体模式不显示系统设置。需要修改 Jellyfin 或其他系统配置时，进入设置页会切回管理模式。

## 启用条件

Jellyfin 媒体模式要求服务器已保存：

```text
jellyfin_url
jellyfin_api_key
```

缺少任一字段时，工作区切换不会进入 Jellyfin 媒体模式；直接打开 `/media`、媒体库、详情或 Jellyfin 播放 URL 也会跳转到设置页的媒体服务区域。

“已配置”和“当前可达”是两个不同状态。Jellyfin 暂时断线时仍可进入媒体模式，由媒体页显示连接错误和设置入口，不会因为一次网络失败就关闭工作区。

从“本地番剧”点击播放会自动切换到媒体工作区，并使用 `/media/local-player` 打开统一播放器；这个流程不要求 Jellyfin 已配置。旧 `/player` 地址仍作为兼容书签保留。

## 页面记忆与播放行为

浏览器会分别记住两个工作区最后打开的页面：

```text
animate.workspace.mode
animate.workspace.last.manage
animate.workspace.last.media
```

从媒体模式切到管理模式时，当前视频会暂停并隐藏，但播放位置和媒体详情仍保留在当前浏览器内存中。切回媒体模式会恢复原页面，不会自动继续播放；点击播放按钮后才恢复。

直接打开媒体路由时会自动进入媒体模式；打开订阅、本地番剧、健康、备份或系统设置等管理路由时会自动进入管理模式。设置页始终属于管理模式。

## 媒体提供商

当前只实现 Jellyfin，但前后端使用提供商无关的媒体模型和 URL。Plex、Emby 等只是设置页中的扩展预留，还不能作为实际媒体提供商使用。

浏览、详情、剧集、图片、进度和收藏请求都先经过 AnimateTool 后端。Jellyfin API Key 保存在服务器设置中，不会暴露给浏览器。
