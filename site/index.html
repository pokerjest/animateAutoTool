01 · OVERVIEW

工具简介

Animate Auto Tool 是一个可以长期运行在自己电脑或服务器上的动漫媒体工作台。

⌁

订阅 Mikan

按季度或关键词发现番组，选择字幕组，并用包含/排除正则控制想要的资源。

◎

管理媒体库

扫描本地文件、匹配番剧和剧集信息，整理为 Jellyfin 与 Plex 容易识别的目录结构。

▶

继续观看

支持 Jellyfin 直连和 AnimateTool 代理，路由切换后保留播放位置并同步共享进度。

⌂

自托管与备份

数据保存在本机 SQLite 和配置文件中，可导出备份、健康日志和诊断包，方便迁移与排错。

02 · INSTALL

安装与启动

普通用户优先下载 GitHub Releases 中的预编译包，不需要安装 Go。

01

选择对应系统的发行包

Windows 选择 _windows_amd64.zip 或单文件 .exe；Apple 芯片选择 _darwin_arm64.dmg；Intel Mac 选择 _darwin_amd64.dmg；Linux 选择对应架构的 .tar.gz。

02

解压到一个固定目录

不要把程序放在临时下载目录。程序会在运行目录旁保存 config.yaml、data/ 和日志目录。

03

启动服务并打开网页

Windows 双击 start.bat；macOS/Linux 执行 ./start.sh。然后打开 http://localhost:8306。

Windows

需要调试时使用 run.bat，停止服务使用 stop.bat。如果 Windows 防火墙弹窗，请允许当前网络环境访问。

macOS / Linux

如果脚本没有执行权限，可以先运行 chmod +x start.sh scripts/*.sh，再启动服务。

Docker

仓库提供 docker-compose.yml 示例。正式使用前请确认 data、下载目录和 qBittorrent 数据目录已经正确挂载。

03 · FIRST RUN

首次初始化

第一次启动请在运行软件的那台电脑上完成初始化，这是系统刻意设置的安全边界。

推荐做法

  1. 在本机打开 http://localhost:8306。
  2. 点击“开始初始化”，设置自己的管理员用户名和密码。
  3. 初始化完成后回到登录页，使用新密码登录。
  4. 之后再按需要配置反向代理、Tailscale 或 IP 白名单。
!

远程设备不能代替本机完成首次初始化。忘记密码时也必须在本机访问 /recover；不要把恢复链接暴露到公网。

05 · SUBSCRIPTIONS

订阅与资源筛选

订阅时可以关联 Mikan 番组、选择字幕组，并用规则筛选清晰度、语言和其他文件名信息。

添加一个 Mikan 订阅

  1. 打开“订阅管理”，点击“添加订阅”或“发现番剧”。
  2. 在“季度番组”或“搜索”里找到目标番剧。
  3. 选择指定字幕组，或选择“全部字幕组”。
  4. 确认最近资源预览，再返回订阅表单。
  5. 填写下载器、保存目录和筛选规则后保存。

字幕组和正则怎么配

指定字幕组时，系统会优先使用字幕组专属 RSS；选择“全部字幕组”时使用聚合 RSS。你仍然可以自己写包含和排除规则。

必须包含
1080p

只接收文件名中带 1080p 的资源。

语言筛选
(?i)(简中|简体)

(?i) 表示忽略大小写。

排除资源
(?i)(1080p WEB-DL|繁中)

命中任意关键词时排除。

!

规则是叠加关系：必须包含规则会缩小结果，必须不含规则会继续排除。规则写得过严时，订阅可能看起来“没有新资源”。

06 · LIBRARY

本地番剧与文件整理

扫描根目录后，应用会识别视频文件、匹配番剧和剧集，并把结果显示在“本地番剧”。

媒体根目录动画
→
系列目录葬送的芙莉莲
→
季度目录Season 01
→
剧集文件S01E01.mkv

扫描建议

  • 把不同番剧放在同一个扫描根目录下的独立目录。
  • 首次扫描等待任务中心显示完成，不要重复点击扫描。
  • 扫描漏项时先检查文件权限、符号链接和目录是否在扫描根目录内。
  • 同一系列不同季度尽量保留清晰的季度信息。

整理前先预览

在“本地番剧”中选择单项或批量整理。系统会先列出原路径、目标路径、冲突、附属字幕/NFO/图片和做种保护状态；确认后才执行，不覆盖已有目标文件。

07 · CALENDAR

追番日历

追番日历用于查看每天更新的番剧。点击海报即可进入详情；从详情添加订阅时会优先关联 Mikan 源。

01

海报加载失败时，应用会尝试浏览器直连、主机代理和默认图片回退。

02

Bangumi ID 不一定能直接命中 Mikan，应用会优先尝试 Mikan 对应的 bgm.tv subject ID，再回退标题匹配。

03

如果没有找到 Mikan 番组，仍可以回到订阅表单手动填写 RSS，不会阻塞订阅。

08 · PLAYER

播放器与播放线路

播放时只需要选择线路，连接地址和凭据统一在系统设置中维护。

Jellyfin 直连

需要 Tailscale 或局域网

  • 观看设备直接请求 Jellyfin。
  • 适合局域网或已经安装 Tailscale 的手机、平板和电脑。
  • 直连持续卡顿 8 秒或不可用时，会从当前位置自动回退到代理。
AnimateTool 代理

适合 Cloudflare 或公网

  • 观看设备只需要能打开 AnimateTool。
  • 适合 Cloudflare Tunnel、反向代理和外部访问。
  • 视频流量经过 AnimateTool 主机，主机上行带宽会成为重要因素。

继续观看

播放器会保存当前用户的观看进度，并与 Jellyfin 共享。回到首页的“继续观看”区域后，点击卡片即可从上次位置恢复；也可以选择“从头播放”。只有真正播放结束才会标记为完成。

09 · BACKUP

备份与恢复

迁移电脑或升级前，建议先在“备份与恢复”中导出备份。

建议备份内容

  • 全量备份：数据库、订阅、下载记录、播放历史和系统配置。
  • 系统设置备份：只迁移连接配置和应用设置。
  • Cloudflare R2 配置备份：只迁移 R2 连接信息，不覆盖其他设置。
!

备份文件可能包含服务地址、Token 和 API Key。请像对待密码一样保存，不要上传到公开仓库或发到公开聊天中。

恢复前检查

确认目标版本支持该备份格式，并先停止正在运行的扫描、整理和下载任务。恢复完成后检查 Jellyfin、qBittorrent 和媒体根目录，再重新扫描受影响的库。

10 · SECURITY

安全与公网访问

本项目可以自托管，但“能打开网页”不等于“已经安全”。

HTTPS公网访问时优先使用 HTTPS，避免登录凭据和 Cookie 明文传输。
trusted_proxies只填写你控制的反向代理 IP，不要填整个公网或内网范围。
本机恢复首次初始化和忘记密码恢复只允许 localhost，不能从外部设备完成。
IP 白名单只添加明确可信的单个 IP 或网段；免密写操作仍受同源保护。
配置文件位置
程序目录/
├── config.yaml       # 系统设置同步副本，含敏感配置
├── data/             # SQLite、bootstrap 和运行数据
└── logs/             # 按小时切分的运行日志

11 · OBSERVABILITY

日志与健康诊断

遇到问题时，先查看健康页和日志，再把必要的信息反馈给开发者。

普通日志

按小时查看运行过程

用于排查订阅检查、扫描、下载、网络请求和播放器代理等常规过程。日志文件会按小时切分，避免单文件无限增长。

健康诊断

只导出需要开发者介入的问题

健康诊断包包含当前异常、运行时状态和脱敏快照。导出下载后会消费掉本次诊断记录，适合直接反馈给开发者。

i

反馈前请同时写清楚：发生时间、访问设备、使用的线路（直连/代理）、操作步骤、是否经过 Cloudflare/Tailscale，以及是否能稳定复现。

12 · TROUBLESHOOTING

常见问题

先判断问题发生在“应用主机”“观看设备”还是“外部服务”，通常能更快定位。

Bangumi API 连接失败，但账号密码验证正常

先在运行 AnimateTool 的主机上测试外网连通性。若主机访问 Bangumi 超时，而浏览器能访问，说明是主机网络、DNS、出口防火墙或代理配置问题；不要只看浏览器是否能打开网页。

手机图片加载失败，电脑却正常

优先检查手机到 AnimateTool 的网络稳定性、图片来源域名和反向代理超时。应用会尝试主机代理和缓存；如果所有来源都失败，请导出健康诊断包。

视频提示加载失败，应该选哪条线路？

Cloudflare 或普通公网访问优先选“AnimateTool 代理”；手机和 Jellyfin 在同一局域网，或手机已连接 Tailscale 时可以选“Jellyfin 直连”。直连持续卡顿时应用会自动回退代理。

qBittorrent 登录成功，但 Cookie 数量显示为 0

Cookie 数量不是唯一判断条件。确认 Web UI 地址、端口、登录接口返回正文和实际 API 会话是否可用；如果 qB 使用 IP/localhost 免认证模式，也应以真实 API 请求结果为准。

扫描出来的数量少于 Jellyfin

确认扫描根目录、文件权限、目录层级和文件扩展名。先让扫描任务完成，再看健康页中的扫描进度和异常；对漏扫或重复条目可以在本地番剧页面重新扫描并整理。
